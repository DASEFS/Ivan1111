How to Use / 使用方法

  1. 点击上方 Copy Code 按钮复制 SVG 代码
  2. 打开你的 index.html 文件
  3. 在你想显示 Logo 的位置粘贴代码（通常在 header 或 hero 区域）
  4. 用 <div style="max-width:300px;margin:0 auto;">...SVG代码...</div> 包裹来控制大小和居中
  5. 保存文件，刷新浏览器即可看到 Logo

提示：如果页面中有多个 SVG，需要把每个 id="bgGrad"、id="goldGrad"、id="navyGrad" 改成不同的 ID 名称，避免冲突。
